# 制作案例：赛后先哄你

整理于 2026-11-05。依据本地提示词、试片检查记录和用户反馈；本轮整理没有重新渲染这些镜头。场景为真人风格成年双人对话，白蓝电竞房、沙发、近距离轻接触。不能直接推广到跑跳、打斗、舞蹈或其他模型。

## 证据怎样理解

- “提示词安排”说明意图，不等于模型严格执行到该毫秒。
- “验片记录”说明先前检查观察到了什么，不是控制变量实验。
- “用户认可/反馈”是观感判断，应与技术通过分别保留。
- 同时更改提示词、引导和分镜的结果，只能作为组合经验。

## 1. 开场位置突变与吸引力是两个问题

初版较远的开场与目标构图变化较大，曾出现人物位置突变。后续固定远景、单首帧走近的版本，验片记录确认稳定，但用户仍认为人物离镜头太远、开局吸引力弱。

V3 改成第一帧已经近距离轻抓衣料问话，并加入反应近景；用户认可了该版方案。动作幅度并非唯一变化，人物在画面中更大、开场直接出现关系和冲突，也改善了可读性。

可迁移判断：先解决空间连续，再判断开场是否及时传达剧情。技术上无闪现不代表开场有效。

证据：[V2 检查记录](<local-project>)、[V3 开场提示词](<local-project>)。

## 2. 落座从拖沓改成过急，再得到自然版本

用户先反馈早版坐下太慢。V2 A03 将动作压缩到 0.15–0.90 秒，要求 1 秒坐稳，并在第 24 帧提供坐姿引导。检查确认其快速下降连续，但用户仍觉得僵硬、太快。动作连续和表演自然是不同评价。

V3 T02 延长动作并加入多张中间姿态图，结果出现下降—上升—再次下降，被弃用。

V3 T02R2 改为单首帧，去掉强制尾帧和密集中间引导；文本描述转髋、前倾平衡、屈膝、向后下方移动、接触坐垫后减速，约 1.6–2 秒完成。已有检查记录约 1.8 秒坐稳，无首轮的反复升降，用户认可该版表现。

可迁移判断：合理时长、身体路径和兼容引导共同影响结果。这组案例未隔离每个因素，不能证明单首帧总优于首尾帧，也不能把 1.8 秒作为所有落座的固定时长。

证据：[V2 A03](<local-project>)、[T02 弃用原因](<local-project>)、[T02R2 提示词](<local-project>)、[本轮验证说明](<local-project>)。

## 3. 轻接触可以及时完成

V3 B06 安排 0.8–1.5 秒抬手触脸，用一张 1.5 秒的接触图引导，然后边保持轻接触边说话。已有检查记录确认一次自然摸脸、人设与淡红脸颊保留、对白匹配。

可迁移判断：接近阶段和接触后的表演分别安排；温柔落实为接触力度与回应。此处一个兼容引导有效，与落座案例共同说明不能简单规定“一律去掉引导图”。实际接触时刻没有逐帧统计。

证据：[B06 提示词](<local-project>)、[V3 检查记录](<local-project>)。

## 4. 连续复合动作与剪辑连接

V2 同一镜头包含接近、额头轻吻、退回、害羞、靠肩，文字要求约 3 秒内进入靠肩。用户认为表现弱、转换太急。

检查指定参考片 55–68 秒后，记录发现约 65 秒已切到靠肩后的另一构图。V3 将亲吻与已靠肩反应设计为独立镜头，靠肩近景先留约 0.6 秒表情，再接台词。

完成状态必须准确：V3 交付预览实际是摸脸后直接切到已靠肩，缺少新生成的唇吻镜头。因此只验证了“已靠肩镜头和该剪辑方案可用”，没有验证“完整唇吻到靠肩序列已经成功”。

证据：[V2 A06](<local-project>)、[V3 分镜](<local-project>)、[B08 提示词](<local-project>)、[预览范围](<local-project>)。

## 5. 三视图与近景承担不同任务

早期角色脸型过度理想化；参考视频的清晰近景用于重新校准后，用户认可人物版本，再据此生成三视图。近景镜头继续使用认可的场景脸部图作为身份锚点。

可迁移判断：三视图有利于服装和体型连续，面部像不像仍应检查足够清晰的近景。人体移动自然与脸部身份稳定要分别验片。

证据：[校准说明](<local-project>)。

## 6. 30fps 与声音的边界

该项目实际流程输出原生 24fps 音画，再逐镜补到 30fps。补帧保持时长，没有用全片加速修正表演。曾遇到插值边界帧不足与下载半成品被读取；后续加入帧数检查和临时文件完整下载后替换。

对白来自 H3 音画联合生成，音频解码器不是专门训练的角色声色模型；说话人编号与固定种子都没有证明跨镜头声色锁定。语音识别用于检查台词。安静片段的响度提升曾引出误识别，随后用原始声音与语音活动判断复核。

这些是本项目流程事实。新部署须检查实际工作流，不能按此推断所有 H3 视频都使用同一音频来源、帧率或节点配置。

证据：[后处理流程](<local-project>)、[静默片段复核](<local-project>)。
